## Braço de sistemas web (novo)

Desenvolve e vende sistemas web para pequenos negócios — começando por barbearias.

**Modelo de negócio:**
- Setup único: R$1.500 – R$2.000 (inclui domínio + hospedagem + suporte 1 ano)
- Após 1 ano: R$129/mês ou cancela

**O que entrega no setup:**
- Landing page personalizada
- Sistema de agendamento online
- Painel admin para o cliente
- Domínio .com.br (conta no nome do cliente)
- Deploy Vercel + Firebase + Cloudinary (contas do cliente)

## Infra por cliente (sistemas web)

Cada cliente tem infra própria e isolada — nunca misturado:
- 1 projeto Firebase (conta deles, Blaze no cartão deles se escalar)
- 1 conta Cloudinary (conta deles)
- 1 projeto Vercel
- 1 domínio Registro.br no nome deles

Custo mensal para a Tecnosup por cliente: R$0

---

## Stack dos sistemas web

- Next.js 15 (App Router) + TypeScript
- TailwindCSS 3.4
- Firebase Auth + Firestore + Admin SDK
- Cloudinary (upload server-side)
- Vercel (deploy)
